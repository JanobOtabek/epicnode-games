GitHub'ga ulanish

O'yinlar saytning GitHub omboriga saqlanadi: . Buning uchun faqat shu omborga ruxsati bor fine-grained token kerak (Contents: Read and write). Token faqat shu brauzer oynasi ochiq turganda saqlanadi va hech qayerga yozilmaydi.

Tokenni olish: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
